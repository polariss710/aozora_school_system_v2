## 1. 同一个错误犯了三次

三次都是「声称一个结构保证，实际只挡住了我刚看到的那个攻击」。按时间：

| 次 | 声称 | 实际被什么绕过 | 谁发现 |
|---|---|---|---|
| 一 | 纯函数签名让错误代码写不出来 | JS 参数表证明不了对象来源；调用方可先把 DOM 值写进可变的 `previewResult` 再传入 | Codex |
| 二 | `Object.isFrozen` 拒绝未冻结快照 | 构造污染对象后手动 `Object.freeze` 即可通过，实测把 `999999.99` 送进 payload | 自查（写交接时） |
| 三 | WeakSet 登记「由本模块冻结」 | `freezeAuthoritativeSnapshot` 是公开导出、无条件登记任意对象；先污染再登记即可，实测同样送进 `999999.99` | Codex |

**每一次的修法都是补上一次的具体攻击，而不是修底下那个属性。**

我真正需要的属性是**来源**：数据来自 API 读取，不来自页面代码。
而只要登记入口是页面可以任意调用的，来源就无从谈起——第三次失败是前两次的必然
延伸，不是新问题。

### 明天的判断标准

在写下任何「结构上不可能」之前，先回答：

> **这个约束的入口，调用方能不能自己构造输入？**

能，它就只是一道检查，不是结构保证。检查有价值，但不能替代数据流证明，
更不该在提交信息里被称作「根本进不去」。

## 2. Codex 的两个 P1

### P1-1 登记入口在页面手里

`js/pages/settlement-online-state.js` 的 `freezeAuthoritativeSnapshot` 是公开导出，
接受任意对象并无条件登记。它确实挡住了手工 `Object.freeze` 冒充，也能防止登记后
的引用被篡改，`structuredClone`／代理／复制合法快照都不能继承登记——**但挡不住
「污染后再登记」**。

两条出路，二选一：

- **把登记移到 API 响应边界**：由 `getStudentSettlementOnlineStatus` 等直接返回
  已登记快照，页面拿不到登记入口。这才是来源约束。
- **降级表述**：只把 WeakSet 描述为「同模块冻结快照的身份标记」，P0 证明改由
  真实 handler 数据流测试承担。

### P1-2 DOM → handler 的缺口没有被结构断言替代

- `settlement-lock-edge-body-test.mjs` 的 **T6 是空转的**：清空调用记录 → 调纯函数
  得到 `false` → 断言记录仍为空。中间没有调用 handler，因果链是断的，必然通过。
- `settlement-lock-amount-boundary-test.mjs` 的场景 5 只能证明页面某处调用了纯函数。

因此这条绕法不会被任何测试抓到：

```
闸门正常放行
  → 用 DOM 值构造一个新的 preview 对象
  → 调用公开的 freezeAuthoritativeSnapshot 登记它
  → 传给 builder
```

`js/pages/settlement-page.js` 的 `handleLockSubmit` 目前**不这么写**，所以现状安全；
但测试防不住有人将来这么改。「靠两条结构约束保证」不成立。

## 3. Codex 指出的其余三点（非阻断）

1. **「真实 Edge body」表述过强。** 桩替换的是整个 Supabase SDK 与 Functions
   transport，捕获的是传给 `supabase.functions.invoke` 的 JS `body` 参数，
   不是 SDK 序列化后的 HTTP body，也不是 Edge 实际收到的请求。
   除远程依赖外链路确为生产实现，`buildLockPayload` 的校验与转换是真的；
   桩的成功响应不掩盖 outbound 校验（传非法 UUID 会在调用桩之前抛错）。
2. **`40000.000 / 40000.00` 不是字面意义上的唯一窗口。** 它是最合适的可辨识
   场景；其他尾零形式等价；若 DOM 与 DB 字符串完全相同，误用 DOM 值在结果上
   无法辨识；别名、中间对象、登记前污染都能形成其他数据流路径。
3. **不同查询串确实产生不同模块实例。** 已动态验证：A 实例登记的快照在 B 实例
   返回 `false`。当前生产图没有故障（页面只以
   `?v=phase-d-settlement-lock-20260825-1` 导入一次），但只要保留 WeakSet，
   **URL 一致性就是一个功能性不变式**，不只是缓存卫生问题。
